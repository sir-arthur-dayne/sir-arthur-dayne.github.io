Политика конфиденциальности

Neochevidno comments — личный инструмент владельца YouTube-канала «НЕОЧЕВИДНО». Он использует YouTube Data API для чтения комментариев под видео этого канала и публикации ответов от имени канала.

  • Приложение получает доступ только к YouTube-аккаунту своего владельца, с его согласия через Google OAuth.
  • Тексты комментариев хранятся только локально на компьютере владельца и используются исключительно для подготовки ответов.
  • Данные не продаются, не передаются третьим лицам и не используются для рекламы.
  • Доступ можно отозвать в любой момент: myaccount.google.com/permissions.

Использование данных, полученных через API Google, соответствует Google API Services User Data Policy, включая требования Limited Use. Приложение использует YouTube API Services; см. также Условия использования YouTube и Политику конфиденциальности Google.

Privacy Policy (English)

Neochevidno comments is a personal tool of the owner of the YouTube channel “НЕОЧЕВИДНО”. It uses the YouTube Data API to read comments on this channel's videos and post replies as the channel.

  • It only accesses the owner's own YouTube account, with consent via Google OAuth.
  • Comment text is stored only locally on the owner's computer and used solely to prepare replies.
  • No data is sold, shared with third parties, or used for advertising.
  • Access can be revoked at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. This app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
